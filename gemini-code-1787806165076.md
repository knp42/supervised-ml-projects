# 🛡️ Real-Time Credit Card Fraud Detection System

An end-to-end Machine Learning pipeline designed to detect fraudulent credit card transactions on highly imbalanced data, featuring model explainability with SHAP.

## 📌 Project Features
* **Extreme Imbalance Management**: Optimized XGBoost cost-sensitive learning (`scale_pos_weight`).
* **Robust Evaluation**: Evaluated using Precision-Recall AUC (PR-AUC) and Recall metrics.
* **Explainable AI (XAI)**: Feature contribution analysis using SHAP TreeExplainer.
* **Production Pipeline**: Served via FastAPI and visual dashboard via Streamlit.

## 📊 Key Results
* **Recall (Fraud Detection Rate)**: 85%
* **PR-AUC Score**: 0.8384
* **ROC-AUC Score**: 0.9734
